# Library Management System - JDBC Starter

## Technology
- Java 17+
- Maven
- MySQL
- JDBC / MySQL Connector/J

## Setup

1. Install JDK 17+ and MySQL.
2. Create the database by running `database/schema.sql`.
3. Open `src/main/java/com/library/util/DBConnection.java`.
4. Change:
   - `USER`
   - `PASSWORD`
5. Import the project as a Maven project.
6. Run `com.library.Main`.

## Current features
